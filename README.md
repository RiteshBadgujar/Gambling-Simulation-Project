# 🎲 Gambling Simulation Project

A Java console application that simulates a gambler's betting activity over a month. The program randomly determines wins and losses for each game, tracks daily performance, identifies the luckiest and unluckiest days, and provides a monthly summary.

---

## 📖 About the Project

The **Gambling Simulation Project** is a Core Java application that models a simple gambling scenario where:

- A gambler starts each day with ₹100.
- Every game is played with a bet of ₹1.
- Each game has an equal chance of winning or losing.
- The simulation runs for **20 days**.
- At the end of the month, the program displays:
  - Total winning days
  - Total losing days
  - Luckiest day
  - Unluckiest day
- Users can choose to simulate another month.

This project demonstrates the use of Java fundamentals, loops, arrays, random number generation, and conditional logic.
